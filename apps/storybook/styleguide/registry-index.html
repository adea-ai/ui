Adea UI — component registry

A shadcn registry for the Adea design system. Add a single component to any Solid project, or open the workshop to review the whole library. 

bunx shadcn@latest add https://adea-ai.github.io/ui/r/button.json
  • Repository and documentation adea-ai/ui
  • The whole registry r/registry.json
  • The design tokens r/theme.json

Every payload is generated from the source and validated against it, so an item cannot name a file that does not exist or omit a dependency it needs.
